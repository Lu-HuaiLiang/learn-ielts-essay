# 雅思写作范文

采用 VitePress 1.6.4 默认主题的文档站，收录 70 篇英文范文及 22 章词汇学习手册。支持按话题、题型及词汇主题查找、全文搜索、幕布笔记、浅色／深色主题及窄屏阅读。

## 本地使用

需要 Node.js 20 或以上。首次运行：

```sh
npm ci
npm run dev
```

打开 http://localhost:4173/ 。开发命令会先生成文档，再启动 VitePress。修改范文数据后运行 `npm run generate` 更新页面。

## 静态构建

```sh
npm run build
npm run preview
```

构建先核对全部原文、分类及词汇覆盖，再生成 125 个文档页面（101 个范文相关页面与 24 个词汇页面），最后将静态站点输出到 `dist/`。预览地址同样为 http://localhost:4173/ ，开发服务和预览服务不能同时占用该端口。

部署时上传 `dist/` 的全部内容。默认部署在域名根目录；若部署在子路径，例如 `/ielts/`，使用 `SITE_BASE=/ielts/ npm run build`。文章使用 `/essays/现有ID.html`，分类入口共用文章地址。站点通过 HTTP 服务访问，不支持双击 HTML 文件离线打开。

## 内容与导航

- 话题：保持原有 22 个话题及文章顺序。
- 题型：同意与否 33 篇、双边讨论 20 篇、利弊权衡 6 篇、原因与措施 3 篇、积极／消极发展 3 篇、混合／直接问答 5 篇。
- 无车日归入利弊权衡；原因加正负评价及直接问答归入混合／直接问答。两篇不同立场的运动员薪酬范文分别保留。
- 每篇的题目、范文、解析、小修说明分别放在独立框格中。题目使用 `info`，范文默认展开，解析和小修说明可分别折叠。解析按段编号并展示论证链；小修说明分开呈现原表达、修订表达和修改原因。
- 每篇范文下方增加默认收起的「词汇与短语积累」，按 `write-ielts-essays-my-style` 的选词方法整理 5–8 项正文表达，配中文含义、句法槽位、来源标记及自拟换话题例句。内容保存在 `data/essay-vocabulary.json`，复用原课程搭配并核对当前正文；生成时校验覆盖、条目数、重复及正文出处。项目内保存全部内容，运行时不依赖 Downloads 中的 skill。
- “范文”旁并排显示「结构化阅读」与「全文翻译」按钮，仅展开时显示；选中模式高亮，两者互斥，再次点击当前模式返回原文。收起再展开保留当前模式，刷新或切换文章恢复原文。结构化视图将每段首句独立展示，其余句子列为分点，首段与结尾段采用相同方式。每句下方用小字展示作用标签与中文说明，复用 `data/teacher/` 的句子标注。两种视图均保留英文正文，移除原稿修订加粗；按 `data/essay-vocabulary.json` 的每篇 5–8 个精选表达显示红色加粗字体（无背景色），悬停可看用法，下方「词汇与短语积累」提供用法与换题例句。参考 `write-ielts-essays-my-style` 的题型大纲、通用核心句型、九主题句型与五主题论证方法，将引题与争议、理由与双方观点、让步反驳、假设与举例、权衡与结论等框架表达用紫色加粗标出，覆盖全部70篇。规则保存在 `scripts/essay-framework.mjs`，只标固定句架，话题填充部分保持原样；重叠规则合并，遇到精选词汇时保留完整词条与用法提示，句架部分优先显示紫色。原文和结构化视图同步显示，深色模式使用浅紫色。运行时不依赖外部 skill，也不改写该 skill 或范文正文。
- 范文标题旁的数字按钮逐段播放预生成的微软美音 MP3；每篇文章按实际段落数显示 4 或 5 个按钮。音色固定为 `en-US-AriaNeural`，不依赖浏览器音色或运行时语音服务。再次点击当前按钮停止，点击其他数字切换段落，收起范文、切换文章或离开页面时停止；加载失败后可再次点击重试。
- 解析恢复原始材料中的逐段说明、论证链及三处小修说明，不加入回忆题或迁移练习。
- 搜索可查找范文标题、编号、英文题目和正文，以及词汇英文、中文释义和词群标题；中英文使用按词分段的全文索引。已按要求移除“本页目录”。

`data/essays.json` 是新站的独立内容源，逐段保留原始正文与加粗。`scripts/essay-library.mjs` 从该数据生成文章、分类和侧栏导航；`site/` 内的 Markdown 和侧栏 JSON 为生成文件，不应直接编辑。主题和配置位于 `site/.vitepress/`。

## 范文音频

音频生成器使用 `edge-tts-universal` 和微软 `en-US-AriaNeural` 音色，将 70 篇范文的 317 个段落写入 `site/public/audio/essays/<essay-id>/p01.mp3` 等静态资源。首次生成需要网络：

```sh
npm install --prefix scripts/audio
npm run generate:audio
```

日常构建只检查音频文件是否完整，不会联网重新生成：

```sh
npm run check:audio
```

部署时必须上传 `dist/` 中包含的全部音频文件；站点可通过 `SITE_BASE` 部署到子路径，播放器会自动使用对应的静态资源前缀。项目不需要 Azure 密钥、后端接口或 serverless 配置。

`data/essay-analysis.json` 保存原有逐段解析与小修说明。结构切换只改变展示方式，不改写正文。

全文翻译沿用结构化阅读的段首句与后续分点布局，在每句英文下方用小字展示中文译文，替代该位置的作用标签和解析说明。全部70篇正文的317段、1066句译文保存在 `data/essay-translations.json`，按文章、段落、句子绑定 `{en, zh}`；生成与校验命令检查覆盖、数量及英文原句一致，缺漏或错位会报错。译文随站点静态打包，无需联网。英文继续保留紫色框架、红色词汇和悬停提示；题目与其他学习区保持现有展示。

## 中英对照 PDF

运行 `npm run export:pdf`，将全部 70 篇范文按现有话题顺序导出为 `output/pdf/雅思范文70篇-中英对照阅读.pdf`。导出先校验原文与译文，保留逐句中英对照、紫色句架与红色词汇，并加入封面、可点击目录、文章书签和页码；不需要启动网站。英文使用项目内的 Merriweather 字体，中文默认嵌入 macOS 的 Arial Unicode 字体；其他系统可通过 `PDF_CJK_FONT` 指定覆盖简体中文的本地 TTF 字体路径。导出中间 HTML 保存在 `tmp/pdfs/`，可在检查后删除。

## 词汇学习

首页和顶部导航的“词汇学习”进入 `/vocabulary/`，总览保留学习方法、跨章路线和覆盖统计。22 章分别阅读，每章顶部提供词群跳转，左侧目录切换章节。附录合为一页，保留重复词对照、义项说明与来源。每词使用独立折叠框，展开显示原始中文释义、3句英中对照例句、常用搭配及标明关系的联想词。搜索和直达单词链接会自动展开对应内容。

内容源为 `materials/vocabulary-handbook.md`，复制自用户提供的《雅思词汇真经》22 主题逻辑词群手册。`scripts/vocabulary-library.mjs` 校验 22 章、313 个词群、3632 条记录及 3592 个不同词形，保留跨章重复词、原释义、Language Takeaway、自拟短文及回忆提示。词表覆盖以手册说明为准，不表示已与纸书逐页核对。

词条框内复用幕布的本地 Merriweather 英文字体与苹方中文回退字体，默认正文15px／600字重，中文译文12.5px；整理例句与关联表达间距，保留原有折叠框的背景、边框、圆角及内边距。不同词性的释义用中文分号「；」分隔，原材料保留。标题栏右侧按「🌐 编号」排列，🌐打开当前单词的有道词条。词汇区不显示标题旁的 #，保留标题 ID 以支持搜索与直达链接。单词标题仅用于展开／收起；例句中标出的当前单词及联想词中的英文链接到各自对应的有道词典，在新标签页打开。

运行 `npm run generate` 或开发／构建命令会自动生成 `site/vocabulary/` 和独立词汇侧栏；不要直接修改生成页面。内容已存入项目，构建不依赖 Downloads 或联网获取词表。补充内容保存在 `data/vocabulary-learning/chapter-XX.json`；生成器核对每词3例句、译文、搭配、联想词及覆盖完整性。每个单词右侧提供🔴／🟢标记，默认红色，点击切换且不触发折叠；按词条编号保存在当前浏览器，刷新、切换章节后仍保留，同源标签页同步。浏览器禁用存储时仍可在当前页面切换。不提供自测或每日复习。

## 单词故事接龙

左侧“词汇学习”下的“单词故事接龙互动”进入独立页面 `/vocabulary/stories.html`，通过主题选择框切换22章；每章顶部也链接到对应故事。故事逐条覆盖手册的3632条词汇记录，按原313个词群及词条顺序串联成小场景，保留跨章重复词。每次点击标题旁固定位置的👉推进一个词；消息区自动滚动到新句，可向上回看。词群选择框支持从本章任一词群开始，进度显示该章实际词数。点击红色单词会在独立弹窗打开对应的有道词典词条；故事页保留原位置。浏览器按章节保存最后展开的词条编号及内部滚动位置，刷新、切换章节或从词条返回均可继续；“重置”仅清除当前章节的阅读位置。支持键盘↓／→每次推进一词，输入框、下拉框、编辑器及搜索弹窗保留原有按键用途；长按、组合键及输入法组合过程不会连续跳词。读到结尾会停留在完成状态，使用独立的重置按钮从头开始。主题保留在 URL hash 中，可刷新恢复主题并使用浏览器前进／后退。

故事文本分章保存在 `data/vocabulary-stories/chapter-XX.json`，每条叙事用 `[[词条编号]]` 指定唯一目标词。生成器从手册读取英文、原释义、词群及定位链接，校验22章、313词群、3632条记录及原顺序完整覆盖；缺词、错序、重复或多余标记会中止生成。完整故事替换原来的12词示范，浏览器逐章验证全部词条接龙及词群跳转。

## 幕布笔记

范文和词汇章节页右侧提供相同的幕布大纲编辑器，窄屏时显示在正文下方。目录、正文和编辑器采用居中的三栏布局；桌面目录与正文相隔15px，正文宽度最高640px，正文与幕布相隔15px，余下空间分配给幕布。左侧目录隐藏滚动条外观，仍可正常滚动。

`mubu-editor/` 直接复制用户提供的 `build-your-own-mubu` 的 React 界面、原始 CSS 和编辑核心，以本地内嵌页面运行，保持工具栏、格式浮层和编辑交互。只适配容器宽度、隐藏文档标题，并接入按文章保存；参考项目本身保持不变。`npm run build:editor` 构建编辑器，开发和完整构建命令会自动执行此步骤。

每篇范文和每个词汇章节使用独立空白笔记，编辑后自动保存到当前浏览器的本地存储，刷新和切换页面后可继续编辑；范文与词汇各章分别存储。顶部状态显示保存结果；清理浏览器站点数据会移除笔记。无需后台或账号，不跨浏览器同步。

笔记正文英文采用与 pomb.us《Build your own React》正文同款的 Merriweather，中文优先使用苹方，默认字号 15px、字重 600，描述颜色为 `#6b6f6b`。英文字体随项目本地打包，无需外部字体服务；许可证位于 `mubu-editor/public/fonts/merriweather-OFL.txt`。桌面正文与编辑器之间保持 15px 间距。

调整后的字号保存为当前浏览器的通用编辑器偏好，刷新、切换文章或重新打开页面都会沿用；没有有效设置时使用默认 15px。浏览器禁止存储时仍可调整本次显示字号。

- Enter 新建同级主题，Tab / Shift+Tab 调整层级，Shift+Enter 添加描述。
- 点击圆点折叠子主题，拖动圆点移动主题，支持撤销／重做与文字格式。
- 工具栏可搜索笔记；Ctrl/⌘+F 在编辑器内打开笔记搜索，Ctrl/⌘+] 聚焦主题，返回按钮回到完整笔记。
- 笔记编辑器与文章的全文搜索、原文／结构切换分别工作。

## 验证

```sh
npm test
npm run verify
npm run build
```

`npm run verify` 对照迁移前的课程和原始材料，核对 70 篇题干、段落、加粗字符及双分类覆盖。单元测试包括迁移保真、分类、页面生成和历史课程测试。

安装了 Google Chrome 后，可在预览服务运行时执行：

```sh
npm run test:browser
npm run test:presentation
npm run test:translation
npm run test:mubu
npm run test:vocabulary
```

浏览器验收核对全部 70 篇静态渲染正文和精选表达高亮，并检查分类导航、共享地址、刷新、目录锚点、键盘操作、主题保存、搜索和窄屏布局。截图保存到 `artifacts/document-site/`；可通过 `COURSE_URL` 指定其他预览地址，通过 `SCREENSHOT_DIR` 指定截图目录。

词汇验收另核对 24 页内部链接、全部 3632 个折叠框／原释义及每词3例句，检查键盘折叠、搜索与直达自动展开、明暗主题、手机布局，以及红绿标记的切换、持久化和词汇幕布的章节隔离与保存；对应截图为 `vocabulary-*.png`。

## 保留的历史材料

根目录原有 `index.html`、`app.js`、`style.css`、课程模型、课程数据、教师教学数据及 `materials/` 均保留，便于追溯。旧阅读器不再作为网站入口，也不打包进新站；新站只引入上述范文与解析。历史教学核对仍可通过 `npm run verify:legacy` 执行。`scripts/build.mjs` 和 `tests/browser.cjs` 仅用于旧双栏阅读器。

参考目录用于文档结构和视觉样式，不导入其文章、统计脚本、域名或其他项目配置。
